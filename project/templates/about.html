Dataset Information

This system is trained on the PlantVillage Dataset, a benchmark dataset containing 54,000+ images of healthy and diseased plant leaves across 38+ classes. The local subset used here includes 16 classes covering Bell Pepper, Potato, and Tomato plants.

How to Run Locally
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train the AI model (takes 20-40 min on CPU)
cd project
python model/train_model.py

# 3. Run the Flask app
python app.py

# 4. Open in browser
# http://127.0.0.1:5000

Demo Mode: If plant_disease_model.h5 is not found, the system runs in demo mode and returns simulated predictions so you can test the UI without training.
